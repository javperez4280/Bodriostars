# Bodriostars

Juego de arena 3 contra 3 hecho en HTML.

## Cómo jugar

Abrí `index.html` en el navegador. No hace falta instalar nada.

## Jugar online

Si activás GitHub Pages en este repositorio (Settings → Pages → Branch: `main`), el juego queda en:

`https://TU-USUARIO.github.io/bodriostars/`

El modo multijugador usa un servidor aparte en Cloudflare Workers.
